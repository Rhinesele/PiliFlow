## 本仓库改动

- [x] 竖屏刷视频（类抖音全屏滑动）
- [x] 应用名：PiliFlow
- [x] 自定义应用图标与关于页标识

其余功能继承自上游 PiliPlus。

<br/>

## 适配平台

- [x] Android
- [ ] 其它平台以实际编译结果为准

<br/>

## 下载

请使用本仓库 **Actions** 编译出的安装包，或自行克隆后本地/CI 编译。

> 注意：本仓库签名与官方 PiliPlus 不同，无法覆盖安装官方包。
